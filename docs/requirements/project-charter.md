# 项目章程 (Project Charter)

## 1. 项目目标
交付**可运行、可测试、可复现、可用于三人课程验收**的校园失物招领系统，建立完整业务闭环：
> 发布信息 → 搜索/匹配 → 提供线索或申请认领 → 核验/沟通 → 交接 → 归还/找回 → 争议与治理

同时完整保留：需求分析、架构设计、接口契约、数据库迁移、自动化测试、缺陷记录、个人贡献证据。

## 2. 产品与交付边界

| 产品 | 本期建设 | 本期不建设 |
|---|---|---|
| 学生端 | uni-app + Vue3 微信小程序，核心业务闭环 | 完整 H5 学生站、原生 App |
| 管理端 | Vue3 + Element Plus Web 后台 | 重复实现学生端功能 |
| 后端 | Spring Boot 单体 + MyBatis + MySQL + 受控文件存储 | 微服务、消息队列、独立搜索引擎 |
| 自动匹配 | 类别/地点/事件时间/关键词的**可解释规则**排序 | 图像识别、大模型裁决、复杂推荐模型 |
| 沟通 | 申请内私密留言、寻物线索反馈、刷新/未读 | 实时聊天、公开电话号码 |
| 身份 | 微信登录(有凭据时)、测试登录、管理员登录 | 真实校园统一身份认证（仅留扩展点） |
| 发布 | 课程环境可部署演示 | 微信平台审核通过 / 全校正式运营 |

## 3. 用户角色

| 角色 | 授权范围 |
|---|---|
| 游客 | 浏览公开招领/寻物、基础检索（本期默认：仅公开列表+详情，不能提交线索/留言/认领） |
| 普通用户 | 登录、编辑自己资料/发布、搜索匹配、提供线索、申请认领、审核自己发布的招领、参与自己的交接与争议 |
| 管理员 | 后台治理、被授权的争议处理、审计查阅及维护操作 |
| 开发测试用户 | 仅隔离开发/测试环境使用模拟登录 |

**身份声明**：登录只证明持有系统登录态，**不证明**用户为在校师生。资料页展示"校园身份未认证"。

## 4. 三人纵向分工

| 成员 | 模块 | 需求前缀 |
|---|---|---|
| A | M1 用户与身份管理 | `FR-AUTH` / `FR-USER` |
| A | M2 后台治理与数据维护 | `FR-ADMIN` / `FR-AUDIT` / `FR-BACKUP` |
| B | M3 信息发布与浏览 | `FR-POST` / `FR-FILE` |
| B | M4 检索与自动匹配 | `FR-SEARCH` / `FR-MATCH` |
| C | M5 认领与交接 | `FR-CLAIM` / `FR-HANDOVER` |
| C | M6 沟通与争议 | `FR-MSG` / `FR-LEAD` / `FR-DISPUTE` |

> 公共基础设施（仓库结构、CI、响应封装、DB 配置、UI 变量）全队共建，不重复计入六个业务模块。

## 5. 外部依赖与阻塞点

| 依赖 | 状态 | 影响 | 处置 |
|---|---|---|---|
| 微信 AppID / 密钥 | ⏳ 待用户提供 | 真实微信登录不可用 | 用受限测试登录跑通全部业务；真实登录列为外部配置 |
| 正式 HTTPS 合法域名 | 未落实 | 真机/正式发布受限 | 开发工具验证；真机测试列为外部阻塞 |
| 学校统一身份认证协议 | 本期明确不接入 | 无 | 仅保留 `CampusIdentityProvider` 扩展点，正式返回 disabled |
| 课程时间表 / 期末专项任务 | 未公布 | 排期与验收范围 | 不预设六周；以教师通知更新；保留专项任务空位 |

## 6. 验收范围（Definition of Done 摘要）
- 学生端完成：测试/微信登录、发布浏览寻物/招领、上传图片、查询筛选、查看匹配、提供线索、申请认领、查看审核、留言、双方确认交接、申请争议、查看个人记录。
- 管理端完成：管理员登录、信息治理、用户限制、争议处理、审计查看、维护操作；无越权入口。
- 后端完成：安全认证、业务校验、事务并发约束、文件权限、匹配排序、审计；接口文档与实现一致。
- 关键状态机、越权、重复提交、并发审核、双向确认、争议暂停、隔离恢复测试通过。
- 一键式开发环境启动、示例环境变量、迁移与种子数据、可复现演示脚本。
- 三角色、每人两模块的独立贡献证据。

## 7. 主要风险
1. 无微信 AppID → 真实登录链路无法端到端验证（缓解：测试登录 + 明确标注阻塞）。
2. 并发一致性（单活跃交接、双向确认、争议竞态）实现难度高（缓解：DB 事务 + 唯一约束 + 真实并发测试）。
3. 三人纵向分工的跨模块接口耦合（缓解：P1 冻结接口契约与跨模块事务所有者）。
4. 真机/性能测试受环境限制（缓解：如实标"待验证"，附环境与执行方法）。

详见 `docs/risks-and-decisions.md`。
