# 软件需求规格说明书 (SRS)

> 版本 0.1（P1 冻结）。以任务书为基线。业务默认值见 `../risks-and-decisions.md`；接口见 `../api/openapi.yaml`；追踪见 `traceability.md`。

## 1. 系统概述
校园失物招领系统，建立完整闭环：**发布 → 搜索/匹配 → 提供线索或申请认领 → 核验/沟通 → 交接 → 归还/找回 → 争议与治理**。
- 学生端：uni-app + Vue3 微信小程序。
- 管理端：Vue3 + Element Plus Web 后台。
- 后端：Spring Boot 3.3 单体 + MyBatis + MySQL 8 + 受控文件存储。

**寻物(LOST)与招领(FOUND)区分**：LOST 由失主发布，获取线索，**不能被直接"认领"**；FOUND 由拾物者发布，他人可申请认领并双方交接。搜索/匹配在**相反类型的公开有效信息**间进行，私密证明与争议资料永不参与公开匹配。

## 3. 功能需求

> 每条格式：输入 / 输出 / 权限 / 前置 / 正常流 / 异常流 / 验收。字段级追踪见 traceability.md。

### M1 用户与身份（A）
- **FR-AUTH-01 微信登录**：输入小程序 code；输出系统会话。权限：公开。前置：有合法 AppID。正常：后端交换凭据、绑定/创建用户、签发会话。异常：无凭据→不可用（改用测试登录）；伪造微信标识不视为已验证。验收：有效凭据登录成功；前端不保存微信密钥。
- **FR-AUTH-02 受限测试登录**：输入 testUser；输出测试会话。权限：仅开发/测试。异常：生产调用→403 `MOCK_LOGIN_DISABLED`。验收：TC-AUTH-01；不同测试用户互不越权。
- **FR-AUTH-03 管理员登录与权限**：独立入口，BCrypt 校验，会话过期，角色校验，安全退出。验收：普通用户无法访问任何后台写；管理员不能由请求参数伪造（TC-AUTH-02）。
- **FR-AUTH-04 会话生命周期**：登录恢复、过期重定向、退出、未授权统一处理。验收：未登录写→401；失效 Token 拒绝；退出后会话失效。
- **FR-AUTH-05 校园认证扩展点**：`CampusIdentityProvider`（Disabled 正式默认 / Mock 仅测试 / University 仅接口）。`GET /auth/campus/capabilities` 返回 disabled。验收：能力接口准确报告 disabled；不假造学校认证。
- **FR-USER-01 用户资料**：查看/编辑本人昵称、头像(可选)、校区(可选)；本人发布/申请索引。验收：只能改自己；不收集非必要证件。
- **FR-USER-02 校园身份展示**：记录 UNVERIFIED 并明确告知。验收：不误标"已认证"。

### M2 后台治理与维护（A）
- **FR-ADMIN-01 信息治理**：筛选、查看公开详情/治理元数据、依原因下架、查看处置历史、授权恢复合规内容。验收：下架后公开列表/匹配消失；业务历史保留；后端二次校验（TC-ADMIN-01）。
- **FR-ADMIN-02 用户治理**：用户列表、状态查看、按原因限制发布/留言/申请、解除限制。验收：限制即时生效于所有对应接口；保留操作人与原因（TC-ADMIN-02）。
- **FR-AUDIT-01 审计日志**：记录下架/恢复、用户限制、认领关键审核、管理员裁决、认证安全事件。验收：含时间/操作人/目标/动作/前后状态；普通用户不可访问或篡改。
- **FR-BACKUP-01 数据备份**：仅授权运维可用，覆盖 DB+受控图片目录，记录批次与校验。验收：生成可识别备份并记录；失败可检测。
- **FR-BACKUP-02 恢复验证**：隔离测试环境恢复脚本与核验。验收：至少一次实际恢复验证留记录；绝不覆盖在用库（TC-BACKUP-01）。

### M3 发布与浏览（B）
- **FR-POST-01/02 发布 LOST/FOUND**：采集标题/类别/描述/地点/事件时间/公开图片/可选校区；FOUND 提示不要公开唯一性证明。验收：合法发布在列表；非法字段报错（TC-POST-01）。
- **FR-FILE-01 安全上传**：格式/大小/数量限制、服务端真实文件类型校验、随机文件名、归属/用途、孤儿清理。验收：非图片/超限拒绝；私密文件不能静态访问（TC-FILE-01）。
- **FR-POST-03 列表与详情**：公开分页列表、类型/类别/校区/状态、详情图片、空态/错误态。验收：仅公开有效内容；私密证据不混入。
- **FR-POST-04 我的发布与编辑**：本人列表/详情/编辑/撤回/状态更新，保留历史。验收：不能编辑他人；有有效申请时禁改关键识别字段（TC-POST-02，`POST_EDIT_LOCKED`）。
- **FR-POST-05 完成/关闭**：LOST 标记已找回；FOUND 经交接标记已归还；支持合规撤回。验收：不允许绕过确认将有有效交接的招领置为已归还。

### M4 检索与匹配（B）
- **FR-SEARCH-01 组合筛选**：关键词/类型/类别/校区地点/事件日期范围/分页/受控排序。验收：空/多条件正确；分页稳定；SQL 无注入（TC-SEARCH-01）。
- **FR-MATCH-01 双向候选匹配**：对单条有效发布查相反类型有效候选。验收：自身/同类型/已关闭/已下架不入选（TC-MATCH-01）。
- **FR-MATCH-02 可解释排序**：`S = 0.40C + 0.25L + 0.20T + 0.15K`，返回分数、命中规则、公开预览；权重集中配置。验收：分数可复算；同分稳定次序；缺字段明确降权。
- **FR-MATCH-03 规则验证**：人工正/负样例，记录准确/失败/阈值依据。验收：报告含误/漏匹配分析；不宣称证明归属。

### M5 认领与交接（C）
- **FR-CLAIM-01 提交申请**：仅对有效 FOUND；证明文字必填、私密图片可选；服务端识别申请人。验收：自认领(403 `SELF_CLAIM_FORBIDDEN`)、重复有效申请、关闭发布、违规文件被拒（TC-CLAIM-01/02）。
- **FR-CLAIM-02 申请列表**：认领人"我的申请"；发布者"收到的申请"。验收：无关用户不能猜 ID 读取。
- **FR-CLAIM-03 审核**：发布者接受/拒绝待审，记原因/时间。验收：仅发布者；不能处理终态申请。
- **FR-CLAIM-04 单活跃交接**：同一 FOUND 至多一份有效交接；接受成功更新发布状态并处理其他待审。验收：两个接受并发只允许一个成功（TC-CLAIM-03，`CLAIM_ACCEPT_CONFLICT`）。
- **FR-CLAIM-05 撤销/失败恢复**：申请人撤销待审；交接前失败经受控动作退回可申请状态，保留历史。验收：终态不复活（TC-CLAIM-04）。
- **FR-HANDOVER-01 双方确认**：已接受申请由双方各自确认，分别存时间/身份，两方齐全才完成。验收：单方确认不完成；重复确认幂等；两边状态一致（TC-HANDOVER-01/02）。
- **FR-HANDOVER-02 终态限制**：已归还/撤回/下架禁止新申请；争议期暂停完成。验收：后端覆盖异常组合；错误码一致。

### M6 沟通/线索/争议（C）
- **FR-MSG-01 申请内留言**：双方在申请详情发送/读取文本；显示顺序/时间/简单未读。验收：非参与者不可读；过滤违规/长度；不要求 WebSocket。
- **FR-LEAD-01 寻物线索反馈**：对有效 LOST 提交私密线索；发布者查看。验收：不把 LOST 接入认领；线索仅相关人可见（TC-LEAD-01）。
- **FR-LEAD-02 线索处理**：提交者查看本人记录；发布者标已查看/有帮助/已关闭；寻回后关闭原信息。验收：不擅定归属；日志保留。
- **FR-DISPUTE-01 发起争议**：相关方在有效交接期提交原因/说明/受保护证据。验收：未关联/已结束不允许申诉者不能提交；创建后暂停交接完成（TC-DISPUTE-01）。
- **FR-DISPUTE-02 争议处理**：授权管理员受限查看证据、记调查备注、裁决(CONTINUE/TERMINATE_REOPEN/CLOSE)。验收：每裁决有权限校验/审计/明确状态后果（TC-DISPUTE-02）。
- **FR-DISPUTE-03 结果可见**：当事人查看状态与允许披露的结论；不展示他人证据。验收：关闭后按裁决恢复/终止，历史可追踪。
