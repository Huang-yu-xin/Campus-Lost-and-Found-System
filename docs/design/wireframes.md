# 低保真页面与交互说明 (Wireframes)

> P1 低保真。重点验证 **LOST 线索** 与 **FOUND 认领** 的区别。所有网络请求需有 加载/空/失败 状态；高风险操作二次确认。

## 1. 学生端 微信小程序（§8.1）

### 1.1 首页 / 信息流
```
[搜索框-------------------] 
[LOST 寻物] [FOUND 招领]
最新信息卡片列表（图+标题+类别+校区+状态）
（空态 / 加载中 / 失败重试）
```
交互：点卡片→详情；点搜索→搜索页；顶部 tab 切类型。

### 1.2 搜索与筛选
筛选：类别、地点/校区、事件日期范围、信息类型；分页/加载更多；结果同首页卡片。

### 1.3 信息详情
- 公开描述+图片、状态、发布者有限公开信息、匹配入口。
- **按类型显示不同主操作**：LOST → 「提供线索」；FOUND → 「申请认领」。
- 若为本人发布：显示「编辑/撤回」，LOST 额外「标记已找回」。

### 1.4 发布 / 编辑
- 类型切换 LOST/FOUND，事件标签动态（丢失时间/地点 vs 拾取时间/地点）。
- 拍照/上传公开图片（压缩+数量上限）；隐私提示（FOUND 不要公开唯一性证明）。
- 输入校验；编辑受限说明（有有效申请后核心字段锁定）。

### 1.5 匹配候选
相反类型候选列表 + 分数 + 命中规则原因；顶部声明「仅供参考，不证明归属」；点候选→详情。

### 1.6 寻物线索（LOST 专属）
- 提交：私密线索描述 + 可选图片。
- 我提供的线索（状态）/ 我收到的线索（发布者视角，标 已查看/有帮助/已关闭）。

### 1.7 认领申请（FOUND 专属）
私密证据文字（必填）+ 私密图片（可选）+ 重复提交防护；结果展示。

### 1.8 申请详情 / 沟通
- 发布者：审核（接受/拒绝+原因）。
- 双方：留言（顺序/时间/未读）、状态时间线、当前参与人操作入口。

### 1.9 交接确认 / 争议
- 双方独立确认；显示「等待对方确认」。
- 发起争议 + 当前进度；**暂停状态禁止确认**（提示 `HANDOVER_PAUSED_BY_DISPUTE`）。

### 1.10 我的
用户资料、**校园身份未认证说明**、我的发布、我的申请、收到的申请、相关线索、退出。

## 2. Web 管理后台（§8.2）

| 页面 | 关键交互 |
|---|---|
| 登录 + 总览 | 管理员鉴权；待治理信息/未决争议/近期处置计数 |
| 信息管理 | 过滤/查看、输入理由下架、合规恢复、治理历史 |
| 用户管理 | 检索/状态、限制/解除+理由、审计链接 |
| 争议处理 | 待处理列表、授权查看关联申请与证据、记录裁决理由、状态变更预览、提交与回查 |
| 审计与维护 | 过滤操作日志、备份执行/校验记录、触发授权备份；恢复走受控离线命令（**无一键生产恢复按钮**） |

后台必须有管理员**路由守卫 + 后端权限校验**；不重复实现学生浏览/发布流程。
